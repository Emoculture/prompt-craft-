# Director Studio

## Русский

**Director Studio** — HTML-приложение для Telegram Mini App, которое помогает создавать готовые промпты для нейросетей.

Доступны четыре режима: **Видео**, **Игры**, **Общение** и **Универсальный**. Приложение поддерживает русский и английский языки, локально сохраняет черновики и историю, а также позволяет редактировать и копировать результаты.

В режиме видео можно задать сцену, действие, ракурс, оптику, движение камеры, освещение, атмосферу, длительность, формат кадра, трёхэтапную структуру и negative prompt.

`index.html` — самостоятельный файл приложения. Разместите его на HTTPS-хостинге и укажите URL в настройках Telegram-бота как Mini App.

Важно: приложение создаёт текстовые промпты, но не подключается к нейросетям и не генерирует медиа. Telegram Stars показаны только как демонстрационный интерфейс: оплата и списание Stars не реализованы.

## English

**Director Studio** is an HTML application for a Telegram Mini App that helps create ready-to-use prompts for AI services.

It offers four modes: **Video**, **Games**, **Conversation**, and **Universal**. The app supports Russian and English, saves drafts and history locally, and lets users edit and copy results.

Video mode supports scene, action, framing, optics, camera movement, lighting, atmosphere, duration, aspect ratio, a three-stage sequence, and a negative prompt.

`index.html` is a standalone application file. Host it over HTTPS and set its URL as the Telegram bot’s Mini App URL.

Important: the app creates prompt text only; it does not connect to AI providers or generate media. The Telegram Stars UI is demonstration-only: payments and Star charging are not implemented.
