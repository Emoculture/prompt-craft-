# 🟣 Director Studio

[🇷🇺 Русский](#русский) · [🇬🇧 English](#english)

## Русский

**Director Studio** — Telegram Mini App для создания промптов, разработки кинематографических сценариев и работы с визуальными референсами.

[**Открыть Director Studio →**](https://emoculture.github.io/prompt-craft-/)

| Возможность | Что делает |
| --- | --- |
| **AI Prompt Generator** | Создаёт промпты в четырёх режимах: видео, игры, общение и универсальные задачи. |
| **AI Enhancement** | Улучшает промпты с Gemini в трёх стилях: Quick, Professional и Creative. |
| **Before / After** | Сравнивает исходный и улучшенный текст с подсветкой добавлений и удалений. |
| **Director Mode** | Создаёт сценарии из 3, 5 или 10 сцен с таймлайном и видеопромптами. Действие сцены можно отредактировать, а сцену — перегенерировать отдельно. |
| **Image to Prompt** | Анализирует JPG, PNG и WebP и создаёт промпт по изображению. |
| **Library** | Предлагает локальную историю промптов, поиск, избранное и сохранение сценариев и промптов по фото. |
| **RU / EN** | Русский и английский интерфейс. |

Для функций Gemini откройте Mini App из чата с [@Director_Studio_AI](https://t.me/Director_Studio_AI) в Telegram.

**Telegram Stars** работает в деморежиме. Реальные покупки и списания недоступны.

**Технологии** — HTML, CSS, JavaScript, Telegram Mini Apps, Google Gemini API, Cloudflare Workers и GitHub Pages.

## English

**Director Studio** is a Telegram Mini App for writing prompts, building cinematic storyboards, and working with visual references.

[**Open Director Studio →**](https://emoculture.github.io/prompt-craft-/)

| Feature | What it does |
| --- | --- |
| **AI Prompt Generator** | Creates prompts in four modes: video, games, conversation, and general-purpose tasks. |
| **AI Enhancement** | Refines prompts with Gemini in three styles: Quick, Professional, and Creative. |
| **Before / After** | Compares the original and refined text and highlights additions and removals. |
| **Director Mode** | Creates storyboards with 3, 5, or 10 scenes, a timeline, and video prompts. Edit a scene’s action or regenerate the scene individually. |
| **Image to Prompt** | Analyzes JPG, PNG, and WebP images and creates a prompt from the image. |
| **Library** | Offers local prompt history, search, favorites, and storage for storyboards and image prompts. |
| **RU / EN** | Russian and English interface. |

To use Gemini features, launch the Mini App from the [@Director_Studio_AI](https://t.me/Director_Studio_AI) chat in Telegram.

**Telegram Stars** runs in demo mode. Live purchases and charges are unavailable.

**Technologies** — HTML, CSS, JavaScript, Telegram Mini Apps, Google Gemini API, Cloudflare Workers, and GitHub Pages.
